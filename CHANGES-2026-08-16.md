## 6. Image Additions for the Marquee Item

### 6.1 First attempt (JPEG — superseded)

The first attachment arrived as a Telegram **photo**, which transcoded it to JPEG
(`marquee-letters-garlands.jpg`, 49 634 bytes). Deployed in commit `e2456e9`, but the image
had a **flattened black background** because JPEG cannot store transparency.

> ⚠️ **GOTCHA #3 — Telegram photo vs file.** Images sent as *photos* are recompressed to
> JPEG (transparency lost, sometimes black matte). To preserve a transparent PNG, send it in
> Telegram via attach → **File**.

### 6.2 Final asset (transparent PNG — current)

Second attachment arrived as a **document** and kept the original format:

* Path: `public/balloon-menu-images/marquee-letters-garlands.png`
* Size: 525 683 bytes (~513 KB)
* Format: PNG, color type 6 (RGBA — **alpha channel verified**)
* Content: marquee letters "LOVE" with warm bulbs, pink/magenta/white/purple balloon
  garlands on both sides, transparent background — matches the transparent-PNG convention of
  the other 14 menu designs, so it blends onto the white cards.

Menu reference updated `.jpg` → `.png` in the same item block (§3).

```bash
# reproduction
cp <original-png> public/balloon-menu-images/marquee-letters-garlands.png
sed -i 's|marquee-letters-garlands.jpg|marquee-letters-garlands.png|' \
    src/app/balloon-menu/page.tsx
rm public/balloon-menu-images/marquee-letters-garlands.jpg
```
